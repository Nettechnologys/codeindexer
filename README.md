# Code Indexer

Self-hosted MCP code intelligence server.

🌐 https://codeindexer.dev

## About this repository

This repository is the **community and disclosure space** for Code Indexer. It contains:

- `README.md` — this file
- `SECURITY.md` — how to report a vulnerability
- `LICENSE` — terms under which the **files in this repository** are made available
- `docs/security/advisories/` — published security advisories for vulnerabilities that have already been fixed

The Code Indexer software itself is a **proprietary commercial product** distributed as signed binaries (Free, Pro, Security, and Enterprise tiers). It is not open source. The source code is not published here.

## Reporting issues

- Bug reports / feature requests → [GitHub Issues](https://github.com/Nettechnologys/codeindexer/issues)
- Security vulnerabilities → [SECURITY.md](SECURITY.md) (private advisory)
- Published security advisories → [docs/security/advisories](docs/security/advisories/README.md)
